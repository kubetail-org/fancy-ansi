# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/kubetail-org/fancy-ansi/security/advisories/new).
Do not open a public issue.

Include the version, the input that triggers the problem and what it lets an attacker do. We will
reply in the advisory.

## Supported versions

Fixes go into the latest release only. Before 1.0, that means the newest minor version.

| npm dist-tag | Version | Supported |
| --- | --- | --- |
| `latest` | 0.1.x | Yes |
| `next` | 0.2.0 prereleases | Yes |
| — | Anything older | No |
